Built the container. The app answers on the container's https://localhost —
on the host at https://localhost:8443 via the incus proxy device (part of
provision; no ssh forward to run). Details: README § VM.

Browse (internal CA — accept the click-through warning):
  https://localhost:8443/
(:8443 leaves host :8000 free for the dev runserver — both can run.)

Get in / administer (no ssh anywhere; incus exec lands as root):
  ./localvm shell desmo                       # root shell in the container
  ./localvm runasdesmo desmo ./run djangomanage makeloginlink <email>
  ./localvm backup|rewind|portforward <inst> …  # backups, in-place rewind, forwards

Before the first `desmo pi`: the one-time provider auth + model setup
(README § Pi setup) — `./localvm shell`, then `desmo pi`.
